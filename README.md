# Ionic Thrusters
This project, currently in its infancy, is about the simulation and improvement of the Ionic Thrusters in Spacecrafts for propulsion Vacuum and
Microgravity conditions.

This has heavy connection with Fluid Mechanics (specifically Plasmadynamics, Electrohydrodynamics, Magnetohydrodynamics &
Magnetoplasmadynamics) for which we will be using an open-source software Basilisk to simulate the ionization, ionized gas & plasma flow
and the thrust. Involves Multiphysics simulations. 

By which we will be determining how much dependant is the thrust on the ionization and how to increase the ionization efficiency in the
ionization chamber. 

This project is being supervised by Dr. Shyam Sunder Yadav of the Mechanical Department in BITS Pilani, Pilani Campus.
